# Contributing

Build with CMake and run CTest before submitting a change. Include a seed and
starting conditions when reporting a simulation bug; headless JSON output and
an event log make results easier to reproduce.

Keep the simulation independent of SDL. Changes to citizen decisions should
preserve actual neural inference and learning. World mechanics may enforce
physical prerequisites and navigate to targets, but should not secretly replace
the neural policy with a scripted player or city planner.

The desktop clock remains five ticks per second. Once a world starts, UI input
must only affect presentation. Add a regression check for a behaviour change
where it protects a meaningful property, such as resource conservation, learning
or deterministic continuation.

Keep build output and experiment logs out of Git. Document any added asset or
library license. All current pixel graphics and bitmap glyphs are generated by
the code, and no model downloads are required.
